Search and browse your GitHub **Notifications**, **Pull Requests**, **Issues**, and **Repositories** from Tuna. Pull requests and issues are grouped into views such as review requests, assigned, created, and mentioned. You can also turn on **Unread Notifications** and **All Notifications** as their own entries.

Select GitHub Desktop in Tuna and browse it to jump to the same lists.

Add a connection in the extension's settings with a classic personal access token that has the repo, read:org, read:user, and notifications scopes. GitHub Enterprise servers work too.

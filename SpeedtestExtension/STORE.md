Check your internet speed from Tuna. **Run Speed Test** measures download and upload capacity, responsiveness, and idle latency using the network test built into macOS, so there's nothing to install.

The test runs in the background and shows each result when it finishes. Copy any value, or use **Copy Summary** to copy them all on one line.

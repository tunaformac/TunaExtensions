Select some text and choose **Translate** to see it in each of your languages, or **Translate To…** to pick one. You can also start with the command: type `translate to german`, press Return, and type or paste the text. The text box starts with whatever you last copied.

If you only need a hotkey for one language or want to add translation to an existing shortcut, use Apple's **Translate Text** action. You can pass text from Tuna using **Send to Shortcut…**.

Translation runs on your Mac with Apple's own translation, so nothing is sent anywhere. The language you're translating from is detected for you. Each translation is plain text you can copy, paste, or translate again.

Needs macOS 26 or later, and the language pair downloaded under System Settings → General → Language & Region → Translation Languages. If a pair is missing, Translate shows a shortcut to that page.

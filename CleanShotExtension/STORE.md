Run CleanShot X commands from Tuna: **Capture Area**, **Capture Window**, **Capture Full Screen**, **Scrolling Capture**, **Capture Text (OCR)**, **Record Screen**, **All-in-One Capture**, and more, plus **Annotate from Clipboard**, **Open History**, and the desktop icon toggles.

**Recent Captures** shows your latest 100 CleanShot images, newest first, in a preview grid. Open one, or pass it on to any of Tuna's file actions.

Turn on **CleanShot Commands** in Tuna's Sources settings, then select CleanShot X in Tuna and browse it to see everything. You need CleanShot X installed. The direct and Setapp versions both work.

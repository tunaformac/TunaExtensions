# Fancy Text

Turn ordinary text into 49 playful Unicode styles from a Tuna text action.

Requires Tuna 0.94 or later.

Select or type text, run **Make Fancy Text**, then search the listed results by transformed text or
style name. Each result is a normal Tuna text snippet and can be copied, pasted, typed, or passed to
another text action.

Some Unicode styles may not be recognizable by screen readers. Use them with care.

This is a Swift port of the MIT-licensed
[Raycast Fancy Text extension](https://github.com/raycast/extensions/tree/870667fc671801a467deb7c4c7fc72992efe3820/extensions/fancy-text),
created by Pedro Duarte and contributors. It was inspired by
[fancy-fonts-text](https://github.com/waterrmalann/fancy-fonts-generator).

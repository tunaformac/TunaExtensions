# Strongbox Changelog

## 0.2

- Start from the Strongbox app. Tab offers **Copy Password…**, **Copy Username…**, and
  **Copy OTP…**, with the entry name as the third-pane target. Right Arrow opens the vault picker.
- Start from an entry name in Text Mode and choose **Search Password in Strongbox**,
  **Search Username in Strongbox**, or **Search OTP in Strongbox**.
- To start with `pass`, `user`, or `otp` in the first pane, include **Strongbox Commands** in
  global search under **Settings → Sources**. These commands are opt-in on a fresh install.

## 0.1

- Find a Strongbox entry by name and copy its password, username, or one-time code.
- Search one remembered vault, chosen in the launcher, and ask again when it is no longer offered.
- Show a short notice after each copy or failure.
- Clear copied values from the clipboard after 30 seconds.

# Cloud Share Extension Changelog

## 0.1

- First release: Cloud Share files and images to Amazon S3 or S3-compatible storage and copy the
  public link, returned inline; Cloud Share to… picks among several destinations; Cloud Share to
  Shelf and Cloud Share to Shelf via… upload in the background onto Shelf; browse, search, and delete what is
  in the bucket from Cloud Shared; Test Destination checks a setup end to end. Requires Tuna 0.112
  and TunaKit 1.23.0.
